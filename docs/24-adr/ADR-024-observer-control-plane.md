# ADR-024: Observer Control Plane

**Статус:** accepted  
**Дата:** 2026-02-28  
**Связанные:** [ADR-016](../16-adr/ADR-016-non-blocking-sensor.md), [ADR-021](../21-adr/ADR-021-configurable-world.md), [ADR-022](../22-adr/ADR-022-external-observer-overlay.md)

---

## Контекст

После ADR-022 observer стал единым местом внешнего наблюдения:
- он видит поток;
- читает `world /config`;
- читает white `/metrics`;
- показывает timeline и organism view.

Но исследовательский контур остаётся неполным:
- чтобы изменить режим мира, оператор всё ещё должен ходить напрямую в `world /config`;
- observer не показывает внутреннее время агента как отдельный first-class сигнал;
- сравнение "мир изменился" ↔ "агент отреагировал" разорвано между несколькими инструментами.

Это не кризис агента.  
Это кризис **инструмента наблюдения**.

---

## Цель

Сделать observer полноценным **control + observe** инструментом эксперимента:
- менять параметры мира со страницы observer;
- видеть подтверждение изменения в том же интерфейсе;
- вывести внутреннее время агента как наблюдаемую метрику;
- не нарушить агентные инварианты и не превратить observer в часть агента.

---

## Решение

### 1. Observer получает control plane для world

Observer добавляет proxy-эндпоинт:

- `POST /api/world/config`

Он:
1. принимает `WorldConfig`;
2. проксирует его в `POST /config` мира;
3. получает нормализованный ответ от world;
4. обновляет локальный observer state;
5. публикует `config_changed` в timeline;
6. возвращает применённую конфигурацию UI.

### 2. White публикует внутреннее время агента

White добавляет метрику:

- `protozero_sensor_ticks_total`

Смысл:
- один тик = один вызов обработчика `run_sensor_loop`;
- считаются и `Data`, и `Silence`;
- `EOF` не является новым тиком после завершения цикла.

Это не новое внутреннее состояние агента, а **observability surface** white для уже существующего инварианта ADR-016:
- время агента = число сенсорных тиков.

### 3. Observer показывает эту метрику

Observer:
- читает `protozero_sensor_ticks_total` из white `/metrics`;
- включает её в `GET /api/state`;
- отображает её на странице как часть signal board.

---

## Что меняется

| Было | Стало |
|---|---|
| Управление world отдельно через `curl` / прямой API | Управление world из observer UI |
| Внутреннее время агента не видно напрямую | White публикует `protozero_sensor_ticks_total` |
| Observer только наблюдает | Observer наблюдает и управляет средой эксперимента |
| Реакция на изменение мира размазана между инструментами | Эксперимент собирается в одном интерфейсе |

---

## Инварианты

- Observer остаётся внешним инструментом и не становится частью агента.
- Управление `world` из observer не является motor output агента.
- Логика `black` не меняется.
- Логика `core` не меняется.
- White по-прежнему отличается от black только observability-поверхностью.
- Внутреннее время агента не равно wall-clock времени и публикуется только как счётчик сенсорных тиков.

---

## Новые понятия

| Понятие | Смысл |
|---|---|
| observer control plane | внешний API/UI для управления миром из observer |
| `protozero_sensor_ticks_total` | наблюдаемая метрика внутреннего времени агента |
| agent track | ADR, меняющие сам организм агента |
| observer track | ADR, меняющие исследовательский и наблюдательный контур |

---

## Значение

ADR-024 завершает observer как лабораторный инструмент:
- среда меняется прямо из интерфейса;
- отклик агента виден сразу;
- внутреннее время агента становится наблюдаемым без вторжения в `core`.

Это подготавливает почву для следующего агентного шага:
- перед реализацией ADR-017 теперь можно управляемо вызывать тишину и видеть её эффект.

---

## Acceptance-критерии

1. Observer UI позволяет менять `world config` без прямого обращения к `world`.
2. После изменения конфигурации observer показывает обновлённое состояние мира и публикует `config_changed`.
3. White публикует `protozero_sensor_ticks_total`.
4. Observer читает и показывает `protozero_sensor_ticks_total`.
5. Observer-control не даёт агенту обратной связи напрямую и не нарушает инвариант `world -> agent`.
