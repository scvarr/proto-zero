# ADR-027: Symmetric Consequence of Comparison

**Статус:** implemented, laboratory verification pending  
**Дата:** 2026-08-18  
**Связанные:** [ADR-026](../26-adr/ADR-026-first-internal-drive.md), [Physical Digital Substrate and Evolution Triggers](../00-core/physical-digital-substrate.md)

## Основание

ADR-026 использует результат уже существующего сравнения:

```text
current != previous
```

но причинное последствие получает только один исход:

```text
different → drive_0 += 1.0
equal     → no internal change
```

Текущая анатомия работоспособна; это не intrinsic crisis.

ADR-027 является developmental step: не вводя нового сенсора, памяти или внутренней координаты, сделать причинно значимым второй уже существующий исход сравнения.

## Решение

Первое чтение по-прежнему только устанавливает baseline:

```text
previous = None
current = read(receptor)

→ drive_0 не изменяется
→ previous = current
```

Для каждого последующего чтения:

```text
current = read(receptor)

if current != previous:
    drive_0 += 1.0
else:
    drive_0 -= 1.0

previous = current
```

Оба смещения симметричны по модулю и используют уже установленную фундаментальную внутреннюю единицу `1.0`. Фактический представимый следующий state определяется физическим `f64`.

## Что означает `Equal`

`Equal` означает только `current == previous` для двух последовательных чтений receptor самим агентом.

Это не означает, что World между чтениями не изменял receptor. World может выполнить `42 → 17 → 42`, а агент при двух своих чтениях увидеть `42 → 42` и получить `Equal`.

Следовательно, внутренняя динамика зависит от последовательности состояний, реально наблюдённых процессом агента, а не от полной лабораторной истории World.

## Семантика `drive_0` после ADR-027

`drive_0` больше нельзя интерпретировать просто как количество обнаруженных изменений.

Минимальная операционная семантика:

> сохраняющаяся внутренняя координата накопленного баланса между последовательными наблюдениями различия и равенства receptor-state.

Положительная и отрицательная области не получают семантики «хорошо / плохо», «возбуждение / покой» или «желательно / нежелательно». Ноль остаётся только центром координаты.

## Собственный ход процесса

После ADR-027 повторное наблюдение того же значения тоже изменяет внутреннее состояние.

Это не вводит clock, timestamp, duration или единицу внешнего времени. Агент не знает, сколько физического времени прошло.

Конкретная траектория зависит от реально выполненной последовательности собственных циклов и от состояний receptor, увиденных в этих циклах. Поэтому она также зависит от физического субстрата исполнения процесса.

## White и Black

White и Black имеют один и тот же причинный закон, но не обязаны иметь одинаковые численные траектории `drive_0`.

Instrumentation White может менять скорость его исполнения. Это является отличием физического субстрата конкретного запуска, а не отличием анатомического закона.

World остаётся лабораторной установкой и может использоваться для создания сопоставимых относительных режимов внешней динамики для Black и White.

## Латентная структура `NotEqual`

Для двух `u8` доступны три отношения:

```text
current < previous
current = previous
current > previous
```

Текущий закон причинно различает только два класса:

```text
Equal
NotEqual = Less OR Greater
```

Оба подслучая `NotEqual` пока имеют одно и то же последствие:

```text
Less    → +1.0
Greater → +1.0
```

ADR-027 не материализует `Less` и `Greater` как отдельные причинные ветви Black и не назначает им различную семантику.

Если в будущем появится основание обрабатывать направления различия по-разному, необходимая информация уже содержится в `current` и `previous`.

## Что не вводится

ADR-027 не вводит threshold, reset, clamp, saturation law, decay, стремление к нулю, clock, timer, второй drive, motor, новый sensor или отдельное состояние для `Less` / `Greater`.

## Acceptance criteria

1. Первое чтение receptor только устанавливает `previous` и не изменяет `drive_0`.
2. При `current != previous` выполняется `drive_0 += 1.0`.
3. При `current == previous` выполняется `drive_0 -= 1.0`.
4. Black и White используют одинаковый причинный закон.
5. Новые state variables не вводятся.
6. `Less` и `Greater` не получают разных причинных последствий.
7. Фактический результат арифметики определяется физическим `f64`.
8. Никакой временной единицы, threshold, reset или regulation не вводится.

## Лабораторная проверка

Минимальная проверка подтверждает обе ветви закона:

```text
different → drive_0 increases by one representable internal unit
equal     → drive_0 decreases by one representable internal unit
```

Ручного управления World достаточно для функциональной проверки ADR-027.

Исследование статистической динамики при автономном хаотическом World является отдельным следующим лабораторным этапом.
