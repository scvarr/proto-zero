# ADR-026: First Internal Dynamic Coordinate — `drive_0`

**Статус:** implemented, laboratory verified  
**Дата:** 2026-08-18  
**Связанные:** [ADR-025](../25-adr/ADR-025-change-detection-first-memory.md)

## Контекст

После ADR-025 сущность способна:

```text
read receptor
→ compare current with previous
→ obtain ephemeral changed
→ previous = current
```

`previous` существует потому, что без него невозможно само обнаружение изменения.

Результат `changed` существует только в момент сравнения и отдельно не хранится.

Если изменение обнаружено, после завершения сравнения оно пока не оставляет в сущности никакого сохраняющегося последствия, не необходимого для работы самого сенсора.

## Следующий минимальный шаг

На текущей стадии у сущности нет моторного выхода и она не может воздействовать на мир.

Следовательно, минимальное новое пространство изменения — её собственное внутреннее состояние.

Вводится одна внутренняя динамическая координата:

```text
drive_0: f64
```

`drive_0` — термин внешнего наблюдателя и документации. Сущности не требуется понятие «драйв».

## Закон внутренних динамических координат

Внутренние динамические координаты задаются как знаковые скалярные величины вокруг нуля.

Техническое представление текущей координаты:

```text
f64
```

Нулевая точка:

```text
0.0
```

Ноль является центром координаты, но не является:

- целью;
- нормой;
- желаемым состоянием;
- точкой притяжения;
- условием равновесия.

Отрицательная область допустима самой геометрией координаты, но ADR-026 пока не вводит механизма, который способен переводить `drive_0` в отрицательную сторону.

Специальным значениям IEEE-754 (`NaN`, `+Inf`, `-Inf`, `-0.0`) отдельная семантика не назначается.

## Начальное состояние

При запуске процесса:

```text
previous = None
drive_0 = 0.0
```

`drive_0` является собственной изменяемой переменной процесса.

## Правило изменения

Первое чтение по-прежнему только устанавливает baseline:

```text
previous = None
current = read(receptor)

→ сравнивать не с чем
→ drive_0 не изменяется
→ previous = current
```

При последующих чтениях:

```text
current = read(receptor)

if current != previous:
    drive_0 += 1.0

previous = current
```

Если:

```text
current == previous
```

`drive_0` не изменяется.

## Почему шаг равен `1.0`

На текущей стадии в анатомии нет другой величины, из которой можно вывести силу внутреннего изменения.

Поэтому:

```text
one detected change → +1.0 internal unit
```

является минимальной константой текущего закона.

Она не конфигурируется и не зависит от:

- значения `current`;
- величины разницы между `current` и `previous`;
- количества изменившихся битов;
- времени;
- частоты чтения;
- других драйвов;
- других сенсоров.

Если в будущем появится основание выводить величину изменения из существующей анатомии, это потребует отдельного кризиса и решения.

## Что `drive_0` пока не означает

ADR-026 не назначает `drive_0` семантику.

Он не является автоматически:

- желанием;
- потребностью;
- возбуждением;
- болью;
- удовольствием;
- энергией;
- мотивацией;
- оценкой «хорошо / плохо».

Это только первая сохраняющаяся внутренняя динамическая координата, изменяемая вследствие обнаруженного изменения мира.

## Что сейчас не вводится

ADR-026 не вводит:

- уменьшение `drive_0`;
- decay;
- стремление к нулю;
- homeostasis;
- regulation;
- saturation;
- верхнюю или нижнюю границу;
- нормализацию;
- второй drive;
- motor;
- выбор;
- цель;
- долговременную память между запусками.

Рост `drive_0` сам по себе не объявляется кризисом.

## Black / White

Black содержит ту же причинную цепочку и остаётся немым:

```text
receptor
→ current
→ compare with previous
→ if changed: drive_0 += 1.0
→ previous = current
```

White анатомически эквивалентен Black, но лабораторная instrumentation может дополнительно наблюдать и сохранять:

- текущее значение `drive_0`;
- момент его изменения;
- историю изменений;
- связанные значения `current` и `previous`;
- внешнее лабораторное время и метрики процесса.

Эта instrumentation не является частью Black.

## Acceptance criteria

1. У сущности появляется ровно одна новая собственная динамическая переменная `drive_0`.
2. Тип `drive_0` — `f64`.
3. Начальное значение — `0.0`.
4. Первое чтение receptor не изменяет `drive_0`.
5. Каждое обнаруженное `current != previous` увеличивает `drive_0` ровно на `1.0`.
6. Повторное значение `current == previous` не изменяет `drive_0`.
7. Само значение receptor не определяет величину изменения `drive_0`.
8. Никакого автоматического уменьшения или стремления к нулю нет.
9. `drive_0` не влияет на мир и не создаёт motor output.
10. Black остаётся немым; White позволяет наблюдать `drive_0`.

## Следующий шаг

Реализовать только `drive_0` в Black и анатомически эквивалентном White.

После реализации провести лабораторный эксперимент и не вводить следующий механизм до обнаружения следующей необходимости.
