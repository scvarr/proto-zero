# ADR-021: Configurable World

**Статус:** accepted  
**Дата:** 2025-10-13  
**Связанные:** ADR-020 (Semantic Framing), ADR-014 (Proto-Differential Drive)

---

## Контекст

До сих пор `world` представлял собой статический источник байтов (`/dev/urandom` или фиксированные скрипты).  
В ADR-020 появились **семантические кадры**, что сделало мир содержательно структурированным,  
но он всё ещё был *неизменяемым во времени эксперимента*.

Чтобы исследовать динамику чувствительности и кризисы в реальном времени,  
требуется управляемая среда — **регулируемый источник событий**,  
который можно менять *снаружи*, не перезапуская систему.

---

## Цель

Ввести **настраиваемый мир (Configurable World)** — процесс,  
который генерирует поток байтов в `stdout`, но управляется через HTTP API.

Это позволит:
- менять структуру потока в реальном времени;
- моделировать кризисы (тишину, насыщение, бурсты, шум);
- воспроизводить эксперименты и фиксировать метрики в Grafana.

---

## Решение

Создан отдельный бинарь `protozero_world` (контейнер `world`).

### Поведение

- Генерирует поток байтов в `stdout` (или FIFO).  
- Поддерживает несколько **режимов**:
  - `continuous` — равномерный шум (аналог /dev/urandom);
  - `bursty` — кадры с семантической границей (`\n`);
  - `file_replay` — воспроизведение файла.

- Управляется через HTTP API на `:8080`:
  - `GET /config` — текущая конфигурация;
  - `POST /config` — заменить конфигурацию во время работы.

### Пример конфигурации

```json
{
  "mode": "bursty",
  "bytes_per_sec": 400000,
  "chunk_size": 4096,
  "frame_bytes": 65536,
  "jitter_ms": 20,
  "file_path": "",
  "seed": 42
}
```
---
## Инварианты

- Агентам не передаётся информация о времени.    
- Все задержки (`sleep`) — внутри мира, не нарушают событийность агента.    
- Симметрия black/white сохраняется.    
- Ввод HTTP-API **не является сознанием** мира — только контроль среды эксперимента.    
- Параметры не хардкодятся в агентах.

---
## Новые понятия

|Понятие|Смысл|
|---|---|
|`Mode`|схема генерации мира (`continuous`, `bursty`, `file_replay`)|
|`bytes_per_sec`|внешняя характеристика скорости потока|
|`frame_bytes`|длина «кадра» в байтах (только для `bursty`)|
|`jitter_ms`|флуктуации задержки между чанками|
|`seed`|для детерминированного воспроизведения мира|

---

## Значение

Появляется **управляемая среда** — теперь можно _вводить кризисы экспериментально_,  
а не только дедуцировать их из структуры агента.  
Это фундамент для последующих ADR:

- [[[[ADR-015-crisis-of-silence|ADR-015]] — Crisis of Silence (мир перестаёт подавать события);    
- ADR-023 — Controlled Perturbations (искусственное возбуждение);    
- ADR-024 — Environmental Memory (возвратные зависимости среды).

---

## Acceptance-критерии

1. Мир управляется без перезапуска контейнера.    
2. Агенты получают изменённый поток сразу после POST /config.    
3. Метрики WHITE в Prometheus отражают изменение входного режима.    
4. Симметрия архитектуры (black/white) сохранена.    
5. Код агента не зависит от конкретного режима мира.

---
## Примечание

Это первый ADR, касающийся **эволюции среды**, а не агента.  
Он открывает вторую ось развития Proto-Zero:  
взаимодействие между _внутренними кризисами агента_ и _внешними кризисами мира_.
