# Инварианты (актуально для Stage-1)
1. Нет wall-clock времени внутри агентов: вычисления идут только по событию входа.
2. Нет долговременной памяти между запусками; состояние ограничено локальными переменными процесса.
3. У `black` нет публикации внутреннего состояния и побочного вывода.
4. Симметрия black/white сохраняется: одинаковая агентная логика, `white` добавляет только observability.
5. Поток данных односторонний: `world -> agent`.
6. `drive_0` ограничен диапазоном `[0,1)` формулой `d' = 1/(2-d)`.
7. Кадровое состояние (`frame`) сбрасывается на семантической границе `\n`.

## Базовые инварианты Stage-0
Инварианты Stage-0 остаются методологическим базисом и расширяются текущими ограничениями Stage-1.
