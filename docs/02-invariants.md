# Инварианты (актуально для Stage-1 + ADR-016)
## Agent invariants
1. ~~Нет wall-clock времени внутри агентов~~ → **Время агента = счётчик тиков сенсора** (попыток чтения stdin), не физические секунды (ADR-016).
2. Нет долговременной памяти между запусками; состояние ограничено локальными переменными процесса.
3. У `black` нет публикации внутреннего состояния и побочного вывода.
4. Симметрия black/white сохраняется: одинаковая агентная логика, `white` добавляет только observability.
5. Поток данных односторонний: `world -> agent`.
6. `drive_0` ограничен диапазоном `[0,1)` формулой `d' = 1/(2-d)`.
7. Кадровое состояние (`frame`) сбрасывается на семантической границе `\n`.
8. Сенсор различает три состояния: **Data** (стимул), **Silence** (тишина), **EOF** (смерть) (ADR-016).

## Observer invariants
9. Observer допустим только как внешний слой наблюдения и не может менять агентную логику или подавать агенту обратную связь (ADR-022).
10. Внешний `silence_gap` observer не подменяет внутреннее время агента; это операторская реконструкция, а не агентный факт (ADR-022).
11. Управление `world` из observer относится к control plane среды и не является моторным действием агента (ADR-024).
12. `protozero_sensor_ticks_total` публикуется как observability surface white и не меняет логику `core`/`black` (ADR-024).

## Базовые инварианты Stage-0
Инварианты Stage-0 остаются методологическим базисом и расширяются текущими ограничениями.
Инвариант «нет времени» (ADR-004) снят в ADR-016: организм «попросил» время для различения тишины.
