# ADR-022: External Observer Overlay

**Статус:** accepted  
**Дата:** 2026-02-28  
**Связанные:** [ADR-008](../08-adr/ADR-008-crisis-of-observation-saturation.md), [ADR-016](../16-adr/ADR-016-non-blocking-sensor.md), [ADR-020](../20-adr/ADR-020-semantic-framing.md), [ADR-021](../21-adr/ADR-021-configurable-world.md)

---

## Контекст

После ADR-016 агент начал различать стимул, тишину и смерть.  
После ADR-020 и ADR-021 мир стал структурированным и управляемым.  
WHITE уже публикует Prometheus-метрики, но этого достаточно только для графиков.

Возник новый кризис наблюдения:  
**оператор видит числа, но не видит сам эксперимент как сцену**.

Проблема текущего состояния:
- поток `world -> white` проходит напрямую и не оставляет внешней временной ленты;
- Grafana показывает метрики, но не связывает их с конкретными чанками, кадрами и сменой режима мира;
- визуализация "агента как организма" отсутствует;
- вмешиваться в `core` / `black` / `white` ради richer UI нельзя, чтобы не нарушить инвариант симметрии.

---

## Цель

Ввести **внешнюю надстройку наблюдения** над white-стеком, которая:
- не меняет агентную логику;
- не нарушает black/white symmetry;
- позволяет видеть поток, конфигурацию мира и метрики в одной сцене;
- добавляет живую визуализацию агента как внешнюю интерпретацию, а не часть организма.

---

## Решение

Добавлен отдельный бинарь `protozero_observer` и контейнер `observer`.

Observer работает как **relay + collector + UI**:

1. Читает поток мира из `stdin`.
2. Прозрачно передаёт тот же поток дальше в `stdout` для `white`.
3. Одновременно фиксирует внешние события наблюдения:
   - размер чанка;
   - наличие `\n` как frame boundary;
   - wall-clock разрывы между чанками как **derived external silence**.
4. Параллельно опрашивает:
   - `GET /config` у `world`;
   - `/metrics` у `white`.
5. Отдаёт:
   - `GET /api/state` — агрегированное состояние;
   - `GET /api/events` — SSE-ленту внешних событий;
   - `/` — live UI с timeline и organism view.

В white-стеке прямой маршрут заменён на:

```text
world -> observer -> white
```

Observer не изменяет байтовый поток, а только дублирует его наблюдение.

---

## Что меняется

| Было | Стало |
|---|---|
| `world` пишет прямо в `white` | Поток проходит через внешний relay `observer` |
| Наблюдение = Prometheus + Grafana | Наблюдение = stream timeline + world config + Prometheus + live UI |
| Только графики состояния | Появляется сцена эксперимента |
| Нет визуального тела агента | Появляется внешняя organism-визуализация |

---

## Инварианты

- Логика `black` и `white` не меняется.
- Симметрия black/white сохраняется: observer существует только во внешнем наблюдаемом контуре.
- Поток данных для агента остаётся односторонним: `world -> observer -> white`.
- Observer не вводит новые входы в агента и не публикует агенту обратную связь.
- **Derived silence в observer не равен внутреннему времени ADR-016.** Это только внешняя реконструкция по отсутствию чанков в wall-clock времени.

---

## Новые понятия

| Понятие | Смысл |
|---|---|
| `observer` | внешний контейнер наблюдения, не часть агентной логики |
| relay | прозрачная прокладка потока `stdin -> stdout` с зеркалированием событий |
| observer event | внешнее событие наблюдения (`chunk`, `silence_gap`, `config_changed`, `relay_status`) |
| derived external silence | wall-clock интервал без чанков, вычисленный observer |
| organism view | образная визуализация состояния агента поверх точных метрик |

---

## Значение

ADR-022 фиксирует новый слой архитектуры:  
**наблюдение становится отдельным организмом-инструментом**, а не придатком white-метрик.

Это даёт:
- наглядную timeline эксперимента;
- связку между world config, структурой потока и метриками;
- более сильную визуальную диагностику кризисов;
- основу для будущего self-observation без вторжения в ядро агента.

---

## Acceptance-критерии

1. `white` получает тот же поток байтов, что и без observer.
2. Observer не меняет агентную логику и не требует изменений в `core`.
3. UI показывает:
   - входные чанки;
   - frame boundaries;
   - world config;
   - текущие Prometheus-метрики;
   - внешние silence gaps.
4. Observer-события доступны через HTTP API.
5. При отключении observer white-логика не требует изменений.

## Реализация

Фактически реализовано:
- новый crate `crates/observer`;
- новый контейнер `observer`;
- обновлённый `docker-compose.white.yml` с двумя FIFO: `world-stream` и `agent-stream`;
- observer UI на `:7070`;
- расширенный baseline dashboard Grafana;
- обновлённая документация README и docs.

---

## Примечание

ADR-022 **не вводит внутреннее самонаблюдение агента**.  
Это не реализация ADR-019, а только **внешний зеркальный слой**, который помогает исследователю видеть эксперимент целиком.
