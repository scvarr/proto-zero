# ADR-016: Event-based Decay

**Статус:** draft  
**Дата:** 2025-10-13  
**Связанные:** [ADR-015-crisis-of-silence](../15-adr/ADR-015-crisis-of-silence.md)  

---

## Контекст
ADR-015 выявил необходимость различать «тишину» от насыщения.

## Цель
Реализовать **утихание** возбуждения без использования внешних часов.

## Идея
Определить время через последовательность не-событий:
$$
d ← f(d, s), \quad s ∈ \{0,1\},\ s=1\text{ при событии}
$$
где при \(s=0\) возбуждение постепенно снижается.

## Инварианты
- Нет физических таймеров.  
- Симметрия black/white.  
- Decay вызывается самим процессом чтения.

## Результат
Появление внутреннего ритма без введения clock — минимальный прообраз «времени агента».
