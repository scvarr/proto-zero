# Глоссарий (актуально для Stage-1 + ADR-016)
- Мир (`world`) — внешний источник событийного потока байтов, управляемый через HTTP (`GET/POST /config`).
- Сенсор — non-blocking чтение `stdin` в тиковом цикле (`run_sensor_loop`, ADR-016).
- `SensorEvent::Data` — стимул: данные получены.
- `SensorEvent::Silence` — тишина: попытка чтения не вернула данных, pipe открыт.
- EOF — смерть процесса (pipe закрыт).
- Тик — одна попытка чтения stdin; квант внутреннего времени агента (ADR-016).
- Drive-0 (`drive_0`) — базовое возбуждение в диапазоне `[0,1)`.
- `drive_delta` — локальное изменение состояния (`d_t - d_{t-1}`).
- Кадр (`frame`) — семантический фрагмент потока; граница задаётся маркером `\n`.
- `drive_0_frame` — накопление возбуждения внутри одного кадра.
- Black — немой агент (без публикации состояния).
- White — наблюдаемый двойник black с экспортом метрик Prometheus.
- Моторы — отсутствуют на текущей стадии.

## Исторический контекст
Stage-0 фиксировал минимальный сенсор `HasAny` и базовые инварианты «без времени/без памяти».
ADR-016 снял инвариант «нет времени» — время родилось как счётчик тиков сенсора.
